### 硬件（驱动板、编码器板）

- ##### iFOC-GIM6010

  **安装孔径（对角线）**：44mm，M2-M2.5

  **适用电机**：伺泰威 GIM6010-8、GIM6010-48、GIM8108-8、领控 ME7010
  
  **配合编码器**（可用于 GIM6010-8，GIM8108-8，GIM6010-48）：off_axis_encoder_rev_v1
  
- **iFOC-EL05**

  **适用电机**：异形，仅适配灵足时代 Robstride EL05 电机

  **说明**：hw_rev_v1 版本硬件采用 RS485 通信，后续版本将采用 CANFD 通信。
